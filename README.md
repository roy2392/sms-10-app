# sms-10-app

A Next.js profile app displaying LinkedIn profile photo and link.

## Features
- Single profile page
- LinkedIn profile photo
- Clickable LinkedIn link

## Setup
1. Install dependencies: `npm install`
2. Run locally: `npm run dev`

## Testing
- E2E: Playwright
- Unit: Jest

## Deployment
- Azure Kubernetes Service (AKS)

## Security
- Automated scans: SAST, SCA, secret scanning, container scanning

## CI/CD
- GitHub Actions for build, test, deploy
